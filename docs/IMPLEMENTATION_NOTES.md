# 実装メモ

## 仕様に対する補足

- トップレベルメニューは「自由意志」「大政奉還」の2つのみ。
- 以前の追加要望である「ChatGPT Memoryに入力を委ねるZIP」は、トップレベルを増やさず自由意志配下の補助導線として追加。
- Memory補助はサイトからChatGPTへ接続する機能ではない。ZIPに依頼文を同梱し、利用者がChatGPTへ手動アップロードする。
- 詳細画面の横はみ出し対策として、gridの可変列を `minmax(0, 1fr)` にし、フォーム要素・長文領域に幅制約と折返しを設定。
- 心理質問のUIラベルは一般語にし、尺度名を前面に出さない。内部IDは分析・集計のため保持。
- 詳細心理質問は150問、簡易版はその部分集合60問。同一質問IDを使う。
- 状態監査はconditional likelihoodを相対重みとしても扱えるよう各state/question内で正規化する。生成側には合計約1.0を要求する。
- JSON SchemaはZIP内のschemaファイルを実行せず、アプリに組み込んだ既知schemaで検証する。外部ZIP由来schemaの実行を避けるため。
